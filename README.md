#  Instal·lació d'una màquina virtual

##  Introducció

En aquesta documentacio hos explicare a crear una maquina virtual de Zorin a VirtualBox.

##  Requisits necesaris

* Un ordinador amb Windows
* 8 GB de RAM 
* 30 GB d'espai lliure
* VirtualBox
* Imatge ISO de Zorin
* Connexió a Internet

## 1️ Instal·lar VirtualBox

Primer descarreguem i instal·lem VirtualBox.

![Imatge descarega](/img/image.png)
Seguim els passos de l'instal·lador fins a finalitzar la instal·lació.

## 2️ Crear la màquina virtual

Obrim VirtualBox i seleccionem Nova.

![Nova maquina](/img/Nova.png)

Introduïm el nom de la màquina virtual, despres posem el lloc hon volem que es guardi la maquina i despres tenim que selecionar la iso.

![Creacio maquina](/img/Maquina.png)



Ara tenim que assignar la ram i el numero de procesadors:
    
-   4096MB de ram
- 4CPU

![Ram i Cpu](/img/Ram%20i%20Cpu.png)

Ara que ja tenim la ram i las cpu assignada, ara asignarem el espai de la maquina: 

- 25GB de espai

![Espai](/img/Espai.png)

Una vegada has acabat aixo li dones a finish i inicies la maquina.

![Iniciar](/img/Inicia.png)

## 3 Configuracio de la maquina Zorin

Una vegada has iniciat la maquina, et surt per escollir entre diferents opcions, tens que escollir Try or Install Zorin OS.

![Zorin](/img/Zorin.png)

Una vegada li has donat a Try or Install Zorin OS, tens que esperar a que termini de carregar.

Quan la maquina a acabat de carregar tens que dornarli a la opcio Install Zorin OS.

![Zorin OS](/img/OS.png)

Despres tens que selecionar el idioma que vols.

![Lenguage](/img/Lenguage.png)

Despres en la opcio de updates and another sofwers no toquem res i li donem a continue.

![Update i sofwer](/img/Update.png)

Despres en Installation type selecionem Erase disk and install Zorin OS.

 ![Instal·lacio](/img/Installation.png)

 Despres de fer la instllation et demana que posis don ets, ho fem y li donem a continue.

 ![Lloc](/img/Lloc.png)


Ara el que tenim que fer es posar la nostra informacio:

- El teu nom
- El nom de usuari que vols
- I la contraseña que utilitzaras per inciar sesio

![Log in](/img/Log%20in.png)

Una vegada has finalitzat aquest apartat li donem a continue i esperem a que carregi.

Ara tenim que esperar a que s'installi el Zorin, pot tardar una mica, teniu que espera a que acabi la instal·lacio.

![Installacio Iso](/img/Installar%20Zorin.png)


Una vegada a acabat de instal·lar-se li donem a Restart Now.

![Reiniciar](/img/Reiniciar.png)


## 4 Final del proces

Una vegada li donem a Restart Now, tenim que iniciar sesio amb les dades de avants.

![Inici de sesio](/img/Inici%20de%20sesio.png)

Una vegada ya hem iniciat sesio ya podem utilitar la maquina per el que necesitem.

![Fi](/img/Fi.png)


## 5 Conclusions
Aixo es un tutorial guiat per alguna persona que no sapiga instalar una maquina virtual Zorin, esta explicat pas a pas tot el que necesites fer per que pugis utilitzar la maquina virutal sensa cap mena de problema.
